# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in issues, pull requests, and discussions here is expected to follow it.

In short: be respectful and patient, assume good intent, keep feedback about the work rather than the person, and do not harass, insult, or exclude anyone.

## Reporting

To report behaviour that breaks this code of conduct, use GitHub's **Report content** option on the comment, issue, or pull request, or contact the maintainers privately through the [Parsimap website](https://www.parsimap.ir). Reports are handled confidentially. Maintainers may edit or remove content and block participants who break the code of conduct, as described in the Contributor Covenant's enforcement guidelines.

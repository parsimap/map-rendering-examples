# Parsimap with MapLibre GL JS and Next.js 16 Pages Router

<!-- docs-link:start -->
[MapLibre GL JS Next.js Pages Router guide](https://docs.parsimap.dev/docs/Render%20Maps/maplibre-gl-js-nextjs-pages)
<!-- docs-link:end -->

Copy `.env.example` to `.env.local` and replace the placeholder with your Parsimap token. Install dependencies with `npm install` and start the example with `npm run dev`. The standard example is at `/`; the stateful example is at `/stateful`.

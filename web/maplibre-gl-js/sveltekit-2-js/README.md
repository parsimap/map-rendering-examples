# Parsimap with MapLibre GL JS and SvelteKit 2

<!-- docs-link:start -->
[MapLibre GL JS SvelteKit 2 guide](https://docs.parsimap.dev/docs/Render%20Maps/maplibre-gl-js-sveltekit-2)
<!-- docs-link:end -->

1. Run `npm install`.
2. Copy `.env.example` to `.env` and replace `YOUR_TOKEN_HERE` with your Parsimap token.
3. Run `npm run dev`.

To use the reactive example, import `StatefulMap.svelte` in `src/routes/+page.svelte` in place of `Map.svelte`.

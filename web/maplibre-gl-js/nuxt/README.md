# Parsimap with MapLibre GL JS and Nuxt

<!-- docs-link:start -->
[MapLibre GL JS Nuxt guide](https://docs.parsimap.dev/docs/Render%20Maps/maplibre-gl-js-nuxt)
<!-- docs-link:end -->

1. Run `npm install`.
2. Copy `.env.example` to `.env` and replace `YOUR_TOKEN_HERE` with your Parsimap token.
3. Run `npm run dev`.

To use the stateful example, replace `<Map />` with `<StatefulMap />` in `app/app.vue`.

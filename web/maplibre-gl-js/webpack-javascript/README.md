# Parsimap with MapLibre GL JS, webpack, and Vanilla JavaScript

<!-- docs-link:start -->
[MapLibre GL JS webpack and JavaScript guide](https://docs.parsimap.dev/docs/Render%20Maps/maplibre-gl-js-webpack)
<!-- docs-link:end -->

Install dependencies with `npm install`, then replace `YOUR_TOKEN_HERE` in `src/index.js` with your Parsimap token. Start the example with `npm start` or build it with `npm run build`.

# Parsimap with MapLibre GL JS and Angular

<!-- docs-link:start -->
See the [Parsimap guide](https://docs.parsimap.dev/docs/Render%20Maps/maplibre-gl-js-angular).
<!-- docs-link:end -->

1. Run `npm install`.
2. Copy `src/map-token.example.ts` to `src/map-token.ts` and replace `YOUR_TOKEN_HERE` with your Parsimap token.
3. Run `npm start`.

For the stateful example, import `StatefulMapComponent` from `./stateful-map.component` in `src/main.ts` and pass it to `bootstrapApplication`.

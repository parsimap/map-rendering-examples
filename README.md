Every framework example serves a second page at `/stateful` that keeps the map instance in framework state. The example READMEs explain when to use it.

## Quick start

1. Get a map token from the [Parsimap dashboard](https://dashboard.parsimap.ir/auth/signup).
2. Clone the repository and open an example folder:

   ```sh
   git clone https://github.com/parsimap/map-rendering-examples.git
   cd map-rendering-examples/web/maplibre-gl-js/react-vite
   ```

3. Follow the setup steps in that folder's README. In most examples you run `npm ci`, copy `.env.example` to the env file the README names, set your token, and run `npm run dev`.

## Token safety

A map token used in a web page is visible in the browser's network requests. Never commit a real token: each example reads it from a file that Git ignores, except the CDN examples, where you edit `main.js` directly.

## Package managers

The examples use npm and commit `package-lock.json`. Yarn, pnpm, and Bun also work, but they are not lock-tested. `.nvmrc` sets the Node.js version used in CI; each example's `package.json` lists the versions it supports under `engines`.

## Maintaining the examples

- CI installs, type-checks, and builds every example on each pull request, and checks that the generated README sections are current. Android examples run `./gradlew assembleDebug lint` with JDK 17.
- `scripts/sync-docs-links.mjs` writes each example's documentation link and the table above. An example folder is named after its guide, so `<platform>/<library>/<folder>` (for example `web/maplibre-gl-js/react-vite`) is documented at `/docs/Render Maps/<platform>/<library>/<folder>`. After adding an example to the script, or changing `DOCS_BASE_URL`, run:

  ```sh
  node scripts/sync-docs-links.mjs
  ```

- `node scripts/sync-docs-links.mjs --check-urls` checks that every guide URL loads. A scheduled workflow runs it weekly.
- Dependabot opens one pull request per example for minor and patch updates. Major upgrades are left to maintainers because they also need the guide updated.

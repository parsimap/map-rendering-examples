# Map Rendering Examples

Runnable examples for displaying Parsimap maps.

Each example's documentation link is maintained by `scripts/sync-docs-links.mjs`. Update its shared `DOCS_BASE_URL` when the documentation domain changes, then run:

```sh
node scripts/sync-docs-links.mjs
```

Add each new example's README and documentation path to the script, and wrap its documentation link in the same markers used by the existing example.
